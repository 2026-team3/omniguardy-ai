# Audio V4 실험 안내

V4는 3초 슬라이딩 윈도우마다 점수를 계산하고 녹음의 최대 점수를
`abnormal` 확률로 사용하는 파이프라인입니다.

## 데이터와 라벨

ESC-50만 사용합니다. `audio_guard.labels.TARGET_CLASSES`에 포함된 기존 여섯
카테고리는 `abnormal=1`, 나머지는 `normal=0`입니다. `door_wood_knock`은
노크 이벤트이므로 타깃에 유지합니다. 직접 수집한 정상/비정상 도어락
데이터는 학습과 평가에 사용하지 않습니다.

## 실행

```bash
python -m audio_guard.interfaces.cli.train_cli \
  --pipeline v4 \
  --esc50-dir data/ESC-50 \
  --model-out models/audio_model_v4.keras

python -m audio_guard.interfaces.cli.evaluate_cli \
  --pipeline v4 \
  --esc50-dir data/ESC-50 \
  --model models/audio_model_v4.keras
```

fold 1~3은 학습, fold 4는 threshold 선택, fold 5는 최종 평가에 사용합니다.
기존 도어락 데이터로 파인튜닝한 모델은 이 실험의 기반 모델로 사용하지
않습니다.
