# Audio V5: 파일 단위 MIL 학습 실험

V5는 녹음 파일을 하나의 bag으로 처리합니다. 각 3초 윈도우에 점수를
매기고 가장 높은 점수로 파일 전체의 `normal/abnormal`을 판정합니다.

## 데이터와 라벨

ESC-50 fold 1~3은 학습, fold 4는 검증과 threshold 선택, fold 5는 최종
테스트에 사용합니다. 기존 `TARGET_CLASSES` 여섯 개는 모두
`abnormal=1`이며 나머지 ESC-50 카테고리는 `normal=0`입니다.

직접 수집한 도어락 `normal/abnormal` 데이터는 더 이상 학습, 검증,
파인튜닝에 사용하지 않습니다. 해당 데이터로 파인튜닝한 기존 모델도 새
모델의 기반 가중치로 사용하지 않습니다.

## 실행

```bash
python -m audio_guard.interfaces.cli.train_cli \
  --pipeline v5 \
  --esc50-dir data/ESC-50 \
  --model-out models/audio_model_v5.keras

python -m audio_guard.interfaces.cli.evaluate_cli \
  --pipeline v5 \
  --esc50-dir data/ESC-50 \
  --model models/audio_model_v5.keras \
  --min-recall 0.80

pytest -q tests/test_feature_windows.py tests/test_audio_v5.py
```

`--min-recall`은 선택 사항입니다. 지정하면 fold 4에서 해당 abnormal recall을
만족하는 후보 중 precision과 F1이 높은 threshold를 선택합니다. 지정하지
않으면 F1과 recall 순으로 threshold를 선택합니다. fold 5의 라벨은 threshold
선택에 사용하지 않습니다.

평가가 선택한 모델 경로, 전처리 버전, sample rate, 라벨 매핑, 타깃 목록과
threshold는 모델 옆의 `.config.json`에 저장됩니다. 이 설정 파일을 검토한 뒤
`AUDIO_CONFIG_PATH`로 지정합니다.

V5 특징 추출은 3초 Mel 시간축 전체를 128열로 변환하고 파일당 최대
`max_windows`개의 윈도우를 사용합니다. V3/V4와 입력 분포 및 모델 입력
형태가 다르므로 다른 버전의 모델 가중치를 V5 전처리에 연결하면 안 됩니다.
